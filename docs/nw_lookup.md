## nw lookup

Lookup hostnames, IPs, ISPs, nameservers, and networks.

```
nw lookup [flags]
```

### Examples

```

# Lookup hostname by IP:

	nw lu hn 8.8.8.8

# Lookup hostname by IP and output as json:

	nw lu hn 8.8.8.8 -o json

# Lookup hostname by IP and output as yaml:

	nw lu hn 8.8.8.8 -o yaml

	nw lu ip dns.google.
```
